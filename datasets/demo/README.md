# Demo 数据

threadpool / sql-index 各含 100 条评论、5 段字幕。两套都是独立的合成单作品输入。

- input.json：待导入数据。
- labels.expected.json：独立预期标签，禁止作为真实模型输入。
- report.expected.json：预期统计与证据示例；并非模型产物。
- manifest.json：输入哈希和快照 ID。

每套只有五种文本模板（有意包含相同文本、不同来源 ID 的评论），用于验证 ID 去重、分母与无法判断的边界；不能用来评估真实语义准确率、Macro-F1 或产品效果。第一轮后另做更丰富的人工标注集。

规范化哈希：JSON 对象键排序、紧凑分隔符、Unicode 原文、UTF-8 后做 SHA-256。它是当前 Demo 工具约定；后端跨语言实现需使用同样规范并测试，不能直接对不同格式化的文件字节求哈希。

样本已固定存入仓库；无需安装额外依赖或运行生成器即可验证。
